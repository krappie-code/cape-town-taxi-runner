# 🚐 Cape Town Taxi Runner

An authentic South African minibus taxi endless runner game featuring the Mother City's iconic transport culture!

## 🎮 Play the Game

**Live Demo:** Open `index.html` in any modern web browser!

## 🌍 About

Navigate Cape Town's bustling traffic in a colorful minibus taxi, collecting passengers while dodging potholes, roadwork, and other vehicles. Features authentic Cape Town destinations like Bellville, Wynberg, and Khayelitsha displayed on your taxi's windscreen!

## 🎯 Game Features

### Core Gameplay
- **3-lane endless runner** - Switch lanes to avoid obstacles
- **Jump mechanics** - Leap over potholes and roadwork
- **Passenger collection** - Pick up waiting commuters for points
- **Power-ups** - Fuel boosts, passenger magnets, and shields
- **Increasing difficulty** - Speed and obstacle frequency ramp up over time

### Authentic South African Elements
- **Real taxi destinations** - Bellville, Wynberg, Khayelitsha, Mitchell's Plain, Langa, and more
- **Traditional taxi colors** - Golden yellow with red and green racing stripes
- **Cape Town scenery** - Table Mountain silhouettes and Mother City skyline
- **Local obstacles** - Potholes (very authentic!), roadwork cones, traffic
- **Ubuntu font** - Celebrating South African tech heritage

## 🎮 Controls

### Desktop/PC
- **←→ Arrow Keys** - Switch lanes left/right
- **SPACEBAR** - Jump over obstacles
- **Click** - Alternative control (left/right sides of screen for lanes, center for jump)

### Mobile/Touch
- **Tap left side** - Move to left lane
- **Tap right side** - Move to right lane  
- **Tap center/bottom** - Jump
- Fully responsive and touch-optimized!

## 🚀 Technical Details

- **Pure HTML5/Canvas/JavaScript** - No external dependencies
- **Mobile-responsive** - Works on phones, tablets, and desktop
- **Local storage** - Automatically saves your high score
- **60fps gameplay** - Smooth performance on modern devices
- **Progressive difficulty** - Dynamic speed and spawn rate scaling
